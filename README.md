# 군산시탁구협회 홈페이지 MVP

군산시탁구협회 공식 운영 홈페이지의 초기 MVP입니다.

현재 단계는 실제 운영 데이터와 업무 로직을 붙이기 전의 기본 UI/페이지 구조를 빠르게 배포해 확인하기 위한 버전입니다.

## 현재 확정된 메뉴

- 공지사항
- 조직도
- 동호인리그
- 디비전리그
- 대회일정
- 게시판
- 회원등록/이적
- 로그인 / 회원가입

## 현재 방향

- 국내 체육협회 홈페이지에 가까운 정보 중심 UI
- PC / 모바일 반응형
- 메인 하단: 공지사항 / 대회일정 / 게시판
- 푸터: 군산시탁구협회 공식 운영 홈페이지 문구
- 영문 표기: `GUNSAN TABLE TENNIS ASSOCIATION`

## 다음 단계

실제 협회 자료를 확인한 뒤 아래 기능을 순차 구현합니다.

- 협회 조직도 실제 데이터
- 남자 / 여자 동호인리그 연도별 경기 기록
- 전북탁구협회 대회일정 연동
- 회원 로그인 및 게시판 작성 권한
- 분기별 회원등록
- 클럽별 회장 / 부회장 / 총무 임기 관리
- 회원 이적 신청 / 승인 / 서명 문서 자동화
- 전북탁구협회 제출용 Excel 생성

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.
