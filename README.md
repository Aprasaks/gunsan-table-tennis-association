# 군산시탁구협회 MVP

군산시 탁구협회의 공지, 조직도, 동호인리그, 디비전리그, 대회일정, 게시판, 회원등록/이적 업무를 위한 Next.js 기반 MVP입니다.

## 현재 기본 메뉴

- 공지사항
- 조직도
- 동호인리그
- 디비전리그
- 대회일정
- 게시판
- 회원등록/이적
- 로그인 / 회원가입

## 협회 승인 업무 설정

1. 군산 전용 Supabase 프로젝트에서 `supabase/tournaments.sql`과
   `supabase/mvp-approvals.sql`을 순서대로 실행합니다. 기존 대회 테이블이 있다면
   실제 구조를 먼저 확인합니다. 다른 실험용 테이블이 들어 있는 `schema.sql`은
   이 배포 절차에 사용하지 않습니다.
2. Vercel 프로젝트 환경변수에 `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`,
   `ADMIN_USERNAME=admin`, `ADMIN_PASSWORD`(요청한 암호), 독립적으로 생성한 긴
   `ADMIN_SESSION_SECRET`을 설정합니다. 서비스 역할 키와 관리자 암호는 브라우저 변수에 두지 않습니다.
3. 배포 후 관리자 계정으로 로그인하여 **회원 직책 관리**에서 협회 직책
   (협회장·이사·총무·고문·사무국장)과 구장 직책을 부여합니다. 이전 브라우저 저장소의 회원은
   그 브라우저의 관리자 화면에서 **기존 회원 가져오기**로 회원과 이적 신청을 옮길 수 있습니다.
4. 기존 구장 회장이 정보수정에서 서명을 등록하고 이적을 신청합니다. 새 소속 회장이
   승인하면 모든 협회 직책자에게 협회 승인 대기 건이 표시됩니다. 한 명이 최종
처리하면 나머지 담당자에게 완료 상태로 표시됩니다.

공지사항은 협회 직책을 받은 회원만 작성할 수 있습니다. 공지와 자유게시판 글은
`mvp_posts`에 저장하며, 첫 화면은 그 글과 실제 대회 DB의 일정만 보여줍니다.
구장 담당자가 회원등록 명단을 저장하거나 협회에 제출하면 `mvp_rosters`에 보관됩니다.
희망부 회원가입 또는 희망부 명단 제출 시 `mvp_alerts`에 알림이 생기고, 임원별
읽음 상태는 `mvp_alert_reads`에 기록됩니다. 알림함은 `/admin/notifications`입니다.

군산 사이트 전용 Supabase 프로젝트가 확정되기 전에는 다른 프로젝트(예: DECHIVE)에
이 SQL을 실행하지 마세요. DB와 서버 환경변수를 연결한 후 관리자 로그인, 공지 작성,
회원등록 제출, 희망부 알림, 게시판 수정·삭제를 실제 계정으로 확인해야 합니다.
기존 브라우저의 공지·게시판 글은 자동으로 DB에 옮겨지지 않습니다.

관리자 비밀번호와 세션 비밀값이 아직 배포 환경에 없다면 로그인과 승인 업무는
활성화되지 않습니다. 과거의 미처리 이적 신청을 가져오면 새 소속 승인 단계부터
진행합니다.
