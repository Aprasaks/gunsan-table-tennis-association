# 군산시탁구협회 MVP

군산시 탁구협회의 공지, 조직도, 동호인리그, 디비전리그, 대회일정, 게시판, 회원등록/이적 업무를 위한 Next.js 기반 MVP입니다.

## 현재 기본 메뉴

- 공지사항
- 조직도
- 동호인리그
- 디비전리그
- 대회일정
- 게시판
- 회원등록/이적
- 로그인 / 회원가입

## 현재 상태

현재는 기본 UI와 메뉴 구조를 우선 구성한 단계입니다.
회원등록/이적, 권한, 리그 기록 관리 등 실제 업무 로직은 이후 순차적으로 연결합니다.

## 기술 스택

- Next.js
- TypeScript
- Supabase 예정
- Vercel
