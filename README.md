# 군산시탁구협회 MVP

군산시 탁구협회의 공지, 조직도, 동호인리그, 디비전리그, 대회일정, 게시판, 회원등록/이적 업무를 위한 Next.js 기반 MVP입니다.

## 현재 기본 메뉴

- 공지사항
- 조직도
- 동호인리그
- 디비전리그
- 대회일정
- 게시판
- 회원등록/이적
- 로그인 / 회원가입

## 협회 승인 업무 설정

1. Supabase SQL 편집기에서 `supabase/mvp-approvals.sql`을 실행합니다.
2. Vercel 프로젝트 환경변수에 `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`,
   `ADMIN_USERNAME=admin`, `ADMIN_PASSWORD`(요청한 암호), 독립적으로 생성한 긴
   `ADMIN_SESSION_SECRET`을 설정합니다. 서비스 역할 키와 관리자 암호는 브라우저 변수에 두지 않습니다.
3. 배포 후 관리자 계정으로 로그인하여 **회원 직책 관리**에서 협회 직책
   (협회장·이사·총무·고문)과 구장 직책을 부여합니다. 이전 브라우저 저장소의 회원은
   그 브라우저의 관리자 화면에서 **기존 회원 가져오기**로 회원과 이적 신청을 옮길 수 있습니다.
4. 기존 구장 회장이 정보수정에서 서명을 등록하고 이적을 신청합니다. 새 소속 회장이
   승인하면 모든 협회 직책자에게 협회 승인 대기 건이 표시됩니다. 한 명이 최종
   처리하면 나머지 담당자에게 완료 상태로 표시됩니다.

관리자 비밀번호와 세션 비밀값이 아직 배포 환경에 없다면 로그인과 승인 업무는
활성화되지 않습니다. 과거의 미처리 이적 신청을 가져오면 새 소속 승인 단계부터
진행합니다.
